HL order anatomy

avg = size ÷ number of orders at the level. A level with few orders and a large avg is one big participant; many orders and a small avg is a crowd.

Sweeps min $

A sweep is one aggressive order filling at 2+ price levels. HL is exact (fills share a hash). BN is a heuristic: consecutive fills with the same millisecond and side.

Feed health

Latency = (receive time + clock offset) − exchange event time. The offset is measured against Binance's server clock (NTP-style, lowest round-trip of 5 samples, refreshed every minute), so these numbers are not skewed by your device clock. Late = corrected latency above 1s. A stream is flagged silent when it exceeds its normal gap.
